# AE Tech Hub

Premium digital-agency website built with TanStack Start, React, TypeScript, Tailwind CSS, Vite and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Content and brand updates

- Business details and WhatsApp number: `src/config/site.ts`
- Services, slides, portfolio, testimonials, FAQs and articles: `src/data/content.ts`
- Hero replacement images: `public/assets/slides/`

The contact form is client-side validated and ready to be connected to your preferred email or CRM endpoint.
